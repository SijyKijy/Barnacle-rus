# Терминология - содержит сведения из игры

| Оригинал | Русский | Правило |
|---|---|---|
| Barnacle | Barnacle | Название игры и имя ИИ остаются латиницей; внутренние идентификаторы не переводятся |
| Lia | Лия | Женский род; имя отображаемого голоса |
| Max / Sarah / Thomas | Макс / Сара / Томас | Имена персонажей; введённое пользователем имя не менять |
| Daniel / Chris | Дэниел / Крис | Единая транскрипция |
| hub | хаб | Игровая общая зона; без замены на "центр" в связанных подсказках |
| spawn | точка появления | В повествовательном тексте и интерфейсе |
| build (noun) | постройка | Объект, не процесс сборки программы |
| building contest / competition | строительный конкурс | Одно событие |
| Door Island | остров дверей | Одна и та же локация в записках и диалогах |
| corruption | искажение | Изменение мира; не "коррупция" |
| decay | распад | Отдельный термин от искажения |
| black growths | чёрные наросты | Не заменять чёрные блоки на наросты, если оригинал различает их |
| chunks | чанки | Технический термин игры |
| Sprint Relic | Реликвия скорости | Название предмета |
| Key Bowl | Чаша ключей | Название предмета |
| Glowstick | Светящаяся палочка | Название предмета |
| High Jump Relic | Реликвия прыжка | Название предмета |
| Chalk / Hammer | Мел / Молоток | Названия предметов |
| Slab / Stair / Pillar | плита / ступень / колонна | Формы блоков; материал согласуется с названием формы |
| Control Room | диспетчерская | Единое название помещения |
| Barnacle Sweeper | Сапёр Barnacle | Название мини-игры, не название существа |
| Easy / Normal / Hard | Легко / Средне / Сложно | Подписи уровней сложности |

Короткое "конкурс" допустимо после установленного "строительный конкурс". Лия говорит о себе в женском роде. Род ИИ в анонимных записках и его речи - грамматическое решение перевода, не установленный пол; личности авторов анонимных записок не додумываются. Подпись R. сохраняется латиницей

Нейтральные статусы: active - "работает", spawned - "существо создано". Единицы: m после расстояния - "м", s в перезарядке - "с"

Команды, имена модов, узлов, текстур, состояния сохранений, проценты форматирования и игровые коды сохраняются. Грубость и намеренно повреждённая речь передаются по оригиналу. Перевод не добавляет объяснений загадок

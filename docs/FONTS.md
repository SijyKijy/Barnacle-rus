# Шрифты

RU использует Arimo: четыре статических начертания из https://github.com/googlefonts/Arimo/tree/main/fonts/ttf, SIL OFL 1.1
Файлы сохраняют внутреннее имя Arimo, а в игре загружаются через псевдонимы Cousine и fallback

Исходный пиксельный шрифт EN не заменяется. В игре это `fonts/Arimo-Regular.ttf`, внутреннее имя rainyhearts Medium
SHA-256 оригинала: `268e13c6353b2555355160f4f74e4c9c35e0c1155a8d6c85dc2c194381829c2b`
Для будущей адаптации кириллицы его можно взять из собственной копии игры; в репозиторий он не включён
